Эта папка больше не используется: арты галереи подгружаются с Pinterest
прямыми ссылками, а список работ лежит в assets/js/gallery.js.

Чтобы добавить или заменить арт, правь window.GALLERY там же:
  src    — ссылка /736x/ для сетки
  full   — та же картинка по ссылке /originals/ для лайтбокса
  title  — подпись
  tag    — категория из window.GALLERY_TAGS
  ratio  — высота, делённая на ширину
  size   — «ширинаxвысота» для подписи
  source — ссылка на первоисточник

Загрузка своих артов в браузере убрана: коллекция только внешняя.

Арты принадлежат их авторам, поэтому файлов в репозитории нет.
